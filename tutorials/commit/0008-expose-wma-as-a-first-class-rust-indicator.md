# 0008 把 WMA 暴露为独立 Rust 指标

## 背景

在 `0007` 里，这个仓库已经把 `WmaState` 作为共享基础件补进了 Rust 核心，并且 `hma` 已经在内部使用它。

但那时有一个明显的结构缺口：

- `WmaState` 已经存在
- `hma` 已经依赖它
- C 侧也一直有稳定的 `wma`
- Rust registry 却还没有真正暴露 `wma`

这会带来两个问题：

1. 功能上不完整
2. 架构上不对称

功能上不完整很好理解：用户明明可以在 C 路径里用 `wma`，但 Rust 迁移后的 registry 里却找不到它。

架构上不对称则更 subtle 一点：

- 我们已经证明 `WmaState` 是对的
- 却还没有把它对应的“最基础公开指标”单独接出来

这会让后面阅读代码的人产生误解，以为 `WmaState` 只是 `hma` 的内部工具，而不是一个可以支撑独立指标和派生指标的通用基础件。

## 主要目标

这次提交只做一件很明确的事：

1. 把 `wma` 本体迁进 Rust registry，并补上 batch / stream 两条路径

这不是大批量迁移，但它能把上一批新加的 `WmaState` 正式收口成一个对外能力，而不是停留在“内部已经有了，但外部还不能用”的状态。

## 改动概览

这次新增了：

- `src/indicators/overlay/wma.rs`

同时做了两处接线：

- 在 overlay 模块里导出 `Wma`
- 在 registry 里注册 `wma`

实现上没有重新发明窗口和权重逻辑，而是直接复用了前一批已经验证过的 `WmaState`。

这样做的意义是：

- `wma` 自己能工作
- `hma` 继续复用同一套基础件
- 后面如果还要做更多 WMA 派生指标，也能建立在同一块共享状态之上

## 关键知识

### 1. 为什么这次提交值得单独存在

有些改动看起来文件少，就容易被误判成“顺手补一下”。

但这次提交其实有一个很明确的结构价值：

- 把“共享内部状态”变成“对外可用的正式指标”

如果不单独补这一笔，仓库会长期处在一种不完整状态：

- 内部数学积木已经有了
- 对外 registry 却还没把最基础那个指标接出来

对人和 AI 协作来说，这种“差最后一小截”的状态很容易在后续工作里被忽略。

### 2. 为什么 `wma` 要复用共享 `WmaState`

`wma` 的 C 版本本身并不复杂，但如果 Rust 里重新手写一遍：

- flat sum
- weighted sum
- 窗口滑动
- warm-up 输出时机

那就等于把上一批刚抽出来的通用逻辑又复制了一遍。

这次直接让 `wma` 建立在 `WmaState` 上，等于是在验证：

- 共享状态不仅能服务复杂指标
- 也能独立承担最基础公开指标

这是判断抽象是否健康的一个很重要标准。

### 3. 为什么 stream 路径也必须一起补

如果只补 batch，不补 stream，会留下一个奇怪的不一致：

- `hma` 这种更复杂的 WMA 派生指标已经能 stream
- `wma` 这个更基础的指标却不行

这在工程结构上说不通，也会让基准测试的覆盖面不完整。

所以这次不是只把 `wma` 注册进去，而是把它完整接进 batch / stream / benchmark 这一整条链。

## 验证

这次实际运行了：

- `cargo fmt --all`
- `cargo test`
- `cargo run --release --bin indicator-bench`
- `./smoke`

结果上：

- `wma` 通过了 Rust golden data 对齐
- `wma` 的 stream 路径通过了 batch-vs-stream 对齐
- release benchmark 已经输出 `wma` 的 batch / stream 性能
- 旧 C 路径仍然全部通过

## 未覆盖项

这次还没有处理：

- 还没有继续迁移更多 WMA 派生指标
- benchmark 仍然没有做 C 与 Rust 的直接对比，也没有性能回归阈值

## 对新手的理解建议

可以把这次提交理解成“把上一批抽出来的 WMA 基础件真正封装成一个对外指标”。

前一批更偏向基础设施：

- 先有 `WmaState`
- 先让 `hma` 跑起来

而这次则把这个基础设施完整闭环成：

- 一个正式注册的 `wma`
- 可批处理
- 可流式运行
- 可进入 benchmark

这类“小而完整”的提交，对人机协作很重要，因为它能把“内部已经差不多了”推进到“外部正式可用了”。
